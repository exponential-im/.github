# Exponential

**The open-source operating system for startups run by people and AI agents: goals, projects, meetings and decisions in one place.**

[Website](https://www.exponential.im) · [Docs](https://www.exponential.im/docs) · [Self-hosting](https://www.exponential.im/docs/self-hosting) · [X](https://x.com/be_exponential) · [LinkedIn](https://www.linkedin.com/company/108621153/)

Your team and your agents work from one shared record. Every project and action traces back to a goal, every agent's work is recorded against the person it works for, and decisions stay attached to the work they shaped. Use the agents you already have: Claude, Cursor or anything that speaks MCP.

## Start here

**The app.** Everything lives here. Use it at [exponential.im](https://www.exponential.im) or run it yourself.

| Repo | What it is |
|---|---|
| [**exponential**](https://github.com/exponential-im/exponential) | Goals and OKRs, projects and actions, meetings, decisions and a CRM, with an AI assistant built in. |

**Use it from your tools and agents.** Each one talks to the same workspace.

| Repo | What it is | Get started |
|---|---|---|
| [**exponential-mcp**](https://github.com/exponential-im/exponential-mcp) | Connect Claude, Cursor or any MCP client to your workspace. | `npx exponential-mcp init` |
| [**exponential-cli**](https://github.com/exponential-im/exponential-cli) | Work with Exponential from your terminal and scripts. | `npm install -g exponential-cli` |
| [**exponential-sdk**](https://github.com/exponential-im/exponential-sdk) | Typed TypeScript client for the Exponential API. | `npm install exponential-sdk` |

Guides: [MCP and SDK](https://www.exponential.im/docs/developers/mcp-and-sdk) · [CLI](https://www.exponential.im/docs/developers/cli)

## Run it yourself

Start your own copy in one click: Postgres, the app and the scheduler, with every secret generated for you.

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/exponential)

Or run the images anywhere Docker runs: `ghcr.io/exponential-im/exponential-app` and `ghcr.io/exponential-im/exponential-scheduler`. See the [self-hosting guide](https://www.exponential.im/docs/self-hosting).
